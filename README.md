The Nuvanta Cybersecurity Dashboard is a front-end cybersecurity visualization platform designed to simulate the experience of a modern Security Operations Center (SOC).

The dashboard presents security-related metrics through interactive charts, threat analytics, geographic attack visualization, system monitoring, and alert management features.

This project demonstrates cybersecurity awareness, data visualization techniques, and modern dashboard design principles.

 Features:
             Interactive security analytics dashboard
             Threat monitoring and incident tracking
             Real-time alert simulation
             Geographic attack visualization
             Dynamic charts and statistics
             System health monitoring
             Live dashboard updates
              Modern cybersecurity-inspired user interface
